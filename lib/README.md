# lib

このプロジェクトだけで使用するライブラリを置くディレクトリです。現在、プロジェクト固有の
ライブラリはありません。

再利用可能なまとまりを追加する場合は、次のようにライブラリごとのサブディレクトリへ配置して
ください。

```text
lib/
└── Example/
    ├── src/
    │   ├── Example.cpp
    │   └── Example.h
    └── library.json   # 必要な場合のみ
```

外部ライブラリはここへコピーせず、バージョンを指定して `platformio.ini` の `lib_deps` で
管理してください。
