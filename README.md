# ControlBarGraph

ESP32 の LEDC（PWM）出力を、車速信号を模したパルス信号として利用するための
PlatformIO / Arduino プロジェクトです。GPIO 27 からデューティ比 50% の矩形波を
出力し、速度値を次の一次式で周波数へ変換します。

```text
frequency [Hz] = speed * 6.472 + 5.070
```

> [!IMPORTANT]
> 現在の既定値は `SERVER` モードですが、HTTP ルートはまだ実装されていません。
> アクセスポイントと Web サーバーは起動するものの、速度を設定する HTTP API は
> 利用できません。現時点で実際に値を変更して試す場合は `SPEED` または `FREQ`
> モードを選び、シリアルモニターから入力してください。

## 将来の統合仕様

今後は排他的な 3 モードを廃止し、Web UI、シリアル速度入力、シリアル周波数入力、デモ動作を
単一のファームウェアへ統合する予定です。ESP32 のルートページには連動する速度スライダーと
テキストボックス、およびデモモードスイッチを設け、シリアル端末から変更した状態も Web UI へ
同期します。起動時はデモを有効にします。

さらに、可変抵抗のアナログ値を速度へ線形変換する手動入力を追加します。ボタンで手動入力を
切り替え、手動入力中は専用 LED を点灯し、Web UI、シリアル、デモからの制御を無効にします。
エラー LED とモード表示 LED はいずれも正極性で、GPIO に `HIGH` を出力すると点灯します。

また、指定 Wi-Fi への接続を試み、タイムアウト時には ESP32 が AP を提供する構成、mDNS、
起動状態を示すエラー LED を追加する予定です。入力の優先順位、状態同期、エラー処理、受け入れ条件を
含む詳細は [統合制御機能の要求仕様](docs/requirements.md) にまとめています。これらはまだ
実装されていないため、以下の説明は引き続き現行コードの動作を示します。

## 主な動作

- ESP32 を Wi-Fi アクセスポイントとして起動
  - SSID: `BarGraqh`（ソースに記載された現在の値）
  - パスワード: `password`
  - IP アドレス: `192.168.0.1/24`
- `esp32.local` として mDNS を開始
- GPIO 27 を LEDC channel 0、12 bit、デューティ値 2048（50%）で駆動
- コンパイル時に選択したモードに応じて、固定値、シリアル入力、または Web
  サーバーを使用
- 115200 bps でデバッグログを出力

より詳しい処理の流れと現状の制約は [設計資料](docs/architecture.md) を参照してください。

## 必要なもの

- ESP32 開発ボード（PlatformIO の `esp32dev` 対応ボード）
- USB ケーブル
- [Visual Studio Code](https://code.visualstudio.com/) と PlatformIO IDE、または
  PlatformIO Core
- パルスを確認するオシロスコープやロジックアナライザー（任意）

## セットアップとビルド

```bash
git clone <repository-url>
cd ControlBarGraph
pio run
```

接続した ESP32 への書き込みとシリアルモニターの開始は次のとおりです。

```bash
pio run --target upload
pio device monitor
```

環境によってはアップロードポートを `platformio.ini` またはコマンドラインで指定して
ください。モニター速度は `platformio.ini` で 115200 bps に設定済みです。

## 動作モード

`src/main.cpp` 冒頭のモード用 `#define` を **1 つだけ** 有効にしてビルドします。
現在は `SERVER` が有効です。

| モード | 起動時 | ループ中の入力 | 現状 |
| --- | --- | --- | --- |
| `SERVER` | ポート 80 の Web サーバーを開始 | HTTP クライアントを処理 | ルート未登録のため設定 API は未実装 |
| `SPEED` | 速度 `100` を出力 | 改行区切りの整数を速度として変換 | 使用可能 |
| `FREQ` | `1000 Hz` を出力 | 改行区切りの整数を Hz として使用 | 非ゼロ入力の呼び出し名に誤記があり、現状はビルド不可 |

たとえば `SPEED` モードにする場合は、`#define SERVER` をコメントアウトし、代わりに
`#define SPEED` を追加します。シリアルモニターから `100` と改行を送ると、およそ
652 Hz を出力します。

> [!WARNING]
> `FREQ` モードの非ゼロ入力処理には `prmWrite` という未定義関数の呼び出しがあり、
> これは `pfmWrite` の誤記と考えられます。本 README はコードの現状を正確に記録する
> ため、この不具合を修正せず明記しています。

## 配線

| ESP32 | 接続先 |
| --- | --- |
| GPIO 27 | パルス信号の入力先 |
| GND | 接続先機器の GND |

ESP32 の GPIO は 3.3 V ロジックです。接続先が要求する電圧、電流、極性を確認し、
必要に応じてレベル変換、バッファ、絶縁回路を使用してください。車両や実機へ接続する
前に、測定器と安全な負荷で信号を確認してください。
